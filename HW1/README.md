# Random Lunch Menu Generator
A small web app that picks a lunch idea for you at random, so you don't have to decide

## Live demo
Link: https://tvinki-26.github.io/LLM-4-RECSYS/HW1/

## Features
 
- Random lunch suggestion with a single click
- Each suggestion is shown with an icon
- No build step, no sign-up
- Responsive layout for desktop and mobile

## How it works
 
1. The page holds a predefined list of 12 lunch items, each with an icon
2. Clicking **Generate Lunch!** runs a JavaScript function
3. The function picks one item from the list at random
4. The selected item is displayed with a short fade-in animation
